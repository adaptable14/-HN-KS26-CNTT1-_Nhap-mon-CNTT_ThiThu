# Website Văn Phòng Phẩm

Website **bán hàng** của cửa hàng _văn phòng phẩm_.
[logo](<a href="https://ibb.co/jk7nLkcG"><img src="https://i.ibb.co/jk7nLkcG/logo-van-phong-pham.png" alt="logo-van-phong-pham" border="0"></a>)


| **Thư mục** | **Nội dung** |
|---|---|
| docs | file nhap_hang.txt - danh sách hàng cần nhập thêm |
| media | logo của cửa hàng |
| data | file Excel đơn bán tháng 10 |
| logs | shop.log và các file báo cáo lọc được |
| backup | bản sao logo để phòng hờ |


Lệnh liệt kê toàn bộ dự án (kể cả file ẩn):

```ls -aR```

-   Tổ chức lại cây thư mục và đổi tên file sang snake_case ✅
-   Lọc log và tạo các file báo cáo✅
-   Triển khai website 🔲

> lưu ý : file `.env`  tuyệt đối **không upload**  dưới mọi hình thức
